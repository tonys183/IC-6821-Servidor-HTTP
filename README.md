## Servidor HTTP

Servidor web desarrollado en Java para atender solicitudes HTTP y servir recursos del sistema de archivos. El proyecto trabaja con los métodos GET y HEAD y la construcción de respuestas con sus encabezados y códigos de estado.

La implementación organiza el procesamiento de solicitudes y respuestas en componentes, aplicando principios de diseño de software. El repositorio incluye el código fuente, pruebas, recursos web y documentación de diseño.
